# Moral / Turquoise — Scenario-Choice

## 1. Game Identity

| Field | Value |
|---|---|
| Modality | Scenario-Choice |
| Unique axis | Integral moral dilemmas requiring holonic prioritisation while honouring all stages |
| Core mechanic | Branching narrative dilemmas where every option represents a different developmental altitude's moral logic |
| Session length | 6–12 minutes per checkpoint |

## 2. Mechanic Specification

**The Holonic Crossroads:** Player faces moral scenarios involving multiple stakeholders at different developmental altitudes. No option is 'wrong' — each represents a valid moral logic at its stage. The integral choice honours all while protecting the most depth for the most span.

- **Multi-Altitude Stakeholders:** Each scenario contains characters operating from Red (power), Amber (duty), Orange (achievement), Green (care), and Turquoise (holonic) moral logic. Player must navigate competing claims without dismissing any stage.
- **Depth-Span Dilemmas:** Scenarios where protecting depth (one highly-developed entity) conflicts with protecting span (many less-developed entities). No formulaic answer — genuine holonic reasoning required.
- **Developmental Honour Choices:** Options that rank developmental stages while simultaneously honouring the dignity of each. The integral choice is never condescending to lower stages.
- **Kosmocentric Edge Scenarios:** Late-game scenarios where holonic ranking itself must be released — where the compassionate response transcends the integral framework. Tests whether player can let go of structure when appropriate.

**Branching consequences:** Each choice ripples through subsequent scenarios. Patterns of choice reveal drive-health and shadow-activation across the full session.

## 3. Shadow Surfacing

| Shadow | How surfaced |
|---|---|
| DA — Ethical Architect | Player requests more information indefinitely, delays choice, asks to 'map the full system' before deciding |
| DAll — Contextual Pluralist | Player selects options that refuse to rank, treats all stakeholder claims as equally valid regardless of depth |
| GA — Premature Compassionist | Player selects kosmocentric options in scenarios requiring holonic precision, bypasses trade-off with 'universal love' |
| GAll — Integral Ethics Fortress | Player makes precise holonic choices but refuses kosmocentric-edge scenarios, selects 'maintain structure' when release is appropriate |

## 4. Catalyst → Experience → Integration

**Catalyst:** Scenarios designed so that no single moral framework resolves them cleanly. The player must hold multiple frameworks simultaneously and act from integral vision-logic.

**Experience:** The felt-sense of holonic moral reasoning — the weight of honouring all stages while still choosing, the tension between ranking and compassion, the courage required to act on integral insight.

**Integration:** Early scenarios allow clear holonic resolution. Mid-game introduces genuine trade-offs. Late-game presents kosmocentric edge cases. The progression mirrors the developmental journey from Green contextual ethics through integral holonic ethics toward kosmocentric release.
