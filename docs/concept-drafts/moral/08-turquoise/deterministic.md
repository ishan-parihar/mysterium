## 1. Modality Identity

- **Module:** Moral / White
- **Modality:** Deterministic
- **Unique Axis:** Objective kosmocentric measurement — spontaneous-ethics accuracy, non-deliberative moral response latency
- **Core Mechanic:** Timed moral-response tasks that measure whether ethical action arises without deliberation

## 2. What This Measures

The deterministic modality captures the objective signature of kosmocentric ethics: moral responses that are both accurate AND non-deliberative. At White, right action should arise faster than deliberation allows — the game measures this latency gap as the primary transparency indicator.

## 3. Shadow Detection

- **2.1 Grasping-at-Rightness:** Elevated response time on morally ambiguous stimuli — player pauses to ensure they're 'right' rather than responding transparently.
- **2.2 Aversion-to-Harm:** Avoidance patterns on stimuli involving unavoidable suffering — response accuracy drops or latency spikes.
- **2.3 Moral Bypassing:** Fast but inaccurate responses — player performs non-attachment without genuine ethical sensitivity.
- **2.4 Moralist-Identity:** Consistency bias — player's responses cluster around a 'moral brand' rather than arising fresh per situation.

## 4. Task Architecture

### 4.1 Spontaneous Compassion Probes

Rapid-presentation ethical micro-scenarios (2-4 second windows). Player selects action. Scoring weights:
- Accuracy (does the response reflect kosmocentric compassion?) — 40%
- Latency (does it arise without deliberation?) — 35%
- Variability (does each response arise fresh, not from template?) — 25%

### 4.2 Non-Deliberative Moral Flanker

Moral stimuli with incongruent distractors. Measures whether kosmocentric response is automatic (unaffected by flankers) or still requires effortful override.

### 4.3 Residual Grasping Detection

Sequences where the 'compassionate' response is ambiguous. Measures whether player can act without certainty — or freezes when rightness is unclear.

## 5. Catalyst → Experience → Integration

- **Catalyst:** Tasks that make residual deliberation visible through latency data
- **Experience:** Player notices the gap between spontaneous compassion and effortful morality
- **Integration:** Response patterns shift toward non-deliberative accuracy — ethics becomes reflex-transparent

## 6. Drive Probing

| Drive | Probe |
|---|---|
| Eros | Does moral response reach toward greater inclusion spontaneously? |
| Agape | Does response release attachment to outcome? |
| Agency | Does response arise with clarity and decisiveness? |
| Communion | Does response attune to the relational field without grasping? |

## 7. Scoring & Adaptation

- Latency thresholds adapt to player's baseline cognitive speed (cross-referenced with Cognitive line data)
- Accuracy scoring uses LLM-evaluated rubrics for kosmocentric alignment
- Residual grasping index = f(latency variance, accuracy clustering, avoidance patterns)
- Difficulty scales by reducing presentation time and increasing moral ambiguity

## 8. Compound Shadow Surfacing

- **Righteous Transparent:** High accuracy + high latency on ambiguous items = still checking
- **Compassion Avoider:** Fast responses but systematic avoidance of harm-laden stimuli
- **Ethics Performer:** Fast + superficially accurate but low variability = template responses
- **Moralist-Identified:** Response profile matches a fixed 'moral identity' rather than situational freshness
