## 1. Modality Identity

| Field | Value |
|---|---|
| Module | Interpersonal / White |
| Modality | Immersive-RPG |
| Unique Lateral | Ecological non-dual relating — whether boundary-transparency appears spontaneously in free-play |
| Core Mechanic | Open-world relational encounters measuring emergent communion without task-framing |

## 2. Task Architecture

2.1 **Unstructured Relational Ecology:** The player inhabits a world populated by NPCs with rich relational lives. No explicit relational tasks are given — the system observes how the player relates spontaneously.

2.2 **Emergent Communion Opportunities:** The world presents relational configurations that invite communion without demanding it. Whether the player enters communion spontaneously is the primary diagnostic.

2.3 **Relational-Field Events:** World events that affect the relational field itself — not individual NPCs but the quality of relating in a region. Player's response reveals field-awareness vs. entity-awareness.

## 3. Shadow Detection Mechanics

| Shadow | Free-Play Signal |
|---|---|
| 2.1 Grasping-at-Other | Seeking out specific NPCs repeatedly; forming fixed relational patterns; 'favourite' partners |
| 2.2 Aversion-to-Other | Avoiding relational density; preferring solo exploration; skirting group configurations |
| 2.3 Relational Bypassing | Engaging relationally but superficially; moving through connections without depth |
| 2.4 Identity-with-Relater | Always initiating relational contact; positioning as the social centre; cannot be found |

## 4. Drive Residual Detection

| Drive | Ecological Signal |
|---|---|
| Eros | Seeking novel relational configurations; restlessness with stable relational fields |
| Agape | Gravitating toward NPCs in distress; service-pattern in free-play |
| Agency | Shaping the relational ecology; building, organising, structuring social space |
| Communion | Dissolving into existing relational configurations; never initiating new ones |

## 5. World Design Principles

5.1 **Relational Density Gradient:** World regions vary in relational density — from solitude to intense communion-fields. Player's navigation pattern is diagnostic.

5.2 **NPC Relational Autonomy:** NPCs relate to each other independently of the player. The player can join, observe, or ignore — all are valid and all are measured.

5.3 **Temporal Relational Arcs:** Relationships in the world evolve over time. The player's relationship to this evolution (grasping at permanence, avoiding attachment, etc.) is diagnostic.

## 6. Catalyst → Experience → Integration

6.1 **Catalyst:** World events that disrupt the relational ecology — a beloved NPC community dissolves, a new relational configuration emerges uninvited.

6.2 **Experience:** The player's spontaneous response to relational-field shifts — without task-framing, the authentic pattern emerges.

6.3 **Integration:** Boundary-transparency appearing spontaneously in novel relational configurations without prior practice in that specific context.

## 7. Scoring

- Spontaneity index: communion arising without task-prompting
- Ecological range: diversity of relational configurations entered
- Field-responsiveness: how player responds to relational-ecology shifts
- Pattern-consistency: whether free-play patterns match structured-modality findings
- Cross-modality validation: immersive-RPG confirms or challenges other modality scores

## 8. Implementation Notes

- This modality is the ecological validator — it confirms whether structured-modality gains transfer to spontaneous behaviour
- NPC relational AI must be sophisticated enough to create genuine relational ecology
- Measurement must be entirely invisible — no prompts, no tasks, no feedback
- Long observation windows required (multiple sessions) for reliable scoring
- World must be compelling enough that relational engagement is intrinsically motivated
- This is the hardest modality to implement — requires the most advanced NPC simulation
