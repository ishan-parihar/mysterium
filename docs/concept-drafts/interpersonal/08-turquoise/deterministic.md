## 1. Modality Identity

| Field | Value |
|---|---|
| Module | Interpersonal / White |
| Modality | Deterministic |
| Unique Lateral | Objective non-dual relating measurement — boundary-transparency metrics, communion accuracy |
| Core Mechanic | Timed relational-field tasks with measurable accuracy and latency |

## 2. Task Architecture

2.1 **Boundary-Transparency Probes:** Player and NPC partner(s) share a relational field visualised as overlapping energy signatures. Tasks require the player to act AS the field rather than as a separate agent acting upon it.

2.2 **Communion Accuracy Tasks:** Simultaneous action-coordination where success requires zero self-referential delay. Measured: latency between field-state change and player response, absence of self-corrective hesitation.

2.3 **Relational-Field Tracking:** Multiple NPC entities shift relational configurations. Player must track the field-as-whole without fixating on any single entity. Measured: gaze-distribution entropy, response uniformity across entities.

## 3. Shadow Detection Mechanics

| Shadow | Detection Signal |
|---|---|
| 2.1 Grasping-at-Other | Fixation on specific NPC; response latency spikes when partner identity is ambiguous |
| 2.2 Aversion-to-Other | Avoidance of certain relational configurations; systematic gaps in field-coverage |
| 2.3 Relational Bypassing | Fast but inaccurate responses — performs communion without actual attunement |
| 2.4 Identity-with-Relater | Self-referential micro-delays; accuracy drops when task removes 'relater' role |

## 4. Drive Residual Detection

| Drive | Residual Signal |
|---|---|
| Eros | Over-reaching toward relational novelty; latency drops for new partners |
| Agape | Over-accommodating; accuracy sacrificed to maintain partner comfort |
| Agency | Micro-leading; initiating field-changes rather than co-arising with them |
| Communion | Micro-following; waiting for field to move rather than being the movement |

## 5. Difficulty Staircase

5.1 **Entry:** Two-entity field, slow configuration changes, clear relational signals.

5.2 **Mid:** Multi-entity field, rapid shifts, ambiguous entity-boundaries.

5.3 **Ceiling:** Field where entities are indistinguishable — player must respond to the field-as-such with no entity-reference.

## 6. Catalyst → Experience → Integration

6.1 **Catalyst:** Task configurations that activate residual grasping — e.g., suddenly making a familiar partner ambiguous.

6.2 **Experience:** The felt-sense of the grasping pattern arising — measured as performance perturbation.

6.3 **Integration:** Spontaneous return to field-transparency without effortful correction. The system detects whether recovery is effortless (integrated) or effortful (compensated).

## 7. Scoring

- Primary metric: communion-accuracy (field-response fidelity)
- Secondary metric: boundary-transparency index (absence of entity-fixation)
- Shadow-specific scores feed module-spec drive-health formula
- Half-life 28 days; max decay 10%

## 8. Implementation Notes

- Requires real-time partner simulation or multiplayer synchronisation
- NPC partners must be indistinguishable from human players at this stage
- Visual field representation must be abstract enough to prevent entity-reification
- All metrics computed server-side to prevent gaming
