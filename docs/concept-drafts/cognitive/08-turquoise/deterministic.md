# Cognitive / White — Deterministic Game

> **Modality:** Deterministic (objective measurement)  
> **Unique lateral:** Trans-rational metrics — direct-knowing accuracy, still-mind duration, effortless-complexity indices. Pure psychophysics of non-dual cognition.

---

## 1. Core Mechanic

**Still-Mind Complexity Engine.** The player faces high-dimensional cognitive tasks (n=5 working memory, multi-rule switching, rapid pattern streams) while the system measures effort-signatures: response-time variance, micro-hesitations, accuracy-under-load curves. The diagnostic target is not whether the player CAN solve — at White, capacity is assumed — but whether solving occurs with or without grasping.

Key task types:
- **Direct-knowing probes:** Patterns solvable by deliberation OR immediate recognition. Latency distinguishes the two.
- **Still-mind holds:** Sustained attention tasks where performance degrades if effort is applied (paradoxical tasks).
- **Effortless-complexity ramps:** Cognitive load increases until effort-signatures appear — the threshold IS the score.
- **Transparency windows:** Brief flashes requiring response faster than deliberation allows — only direct knowing succeeds.

## 2. Shadow Surfacing

### 2.1 Grasping-as-Knowing

Detected when: latency on direct-knowing probes exceeds the deliberation threshold; accuracy is high but response-time variance shows effortful processing. The player solves correctly but through conceptual mediation rather than direct knowing.

### 2.2 Aversion-to-Knowing

Detected when: specific stimulus categories show systematic accuracy drops or avoidance patterns (longer latency + lower accuracy in circumscribed domains). The panoramic awareness has holes.

### 2.3 Spiritual Bypassing

Detected when: the player responds at direct-knowing speed but with below-threshold accuracy — mimicking spontaneity without genuine knowing. Fast-but-wrong indicates performance of non-dual cognition rather than its actuality.

### 2.4 Identity-with-Knowing

Detected when: performance degrades on tasks requiring self-referential dissolution (e.g., "respond as if no one is responding"). Micro-hesitation at the moment the task demands knower-dissolution reveals residual identification.

## 3. Drive Detection

- **Eros residue:** Compulsive accuracy-seeking on ascending difficulty — reaching toward mastery rather than resting in capacity.
- **Agape residue:** Premature disengagement from complexity — returning to simplicity before the task requires it.
- **Agency residue:** Performance improvement when tasks are framed as individual achievement vs. neutral framing.
- **Communion residue:** Performance improvement when tasks are framed as collective benefit vs. neutral framing.

Healthy White: no framing effect. Performance is context-independent.

## 4. Progression Arc

**Phase A — Baseline (sessions 1–2):** Full psychometric battery at maximum complexity. Establish capacity ceiling and effort-signature baseline. Map blind-spot domains.

**Phase B — Paradoxical training (sessions 3–6):** Tasks where trying harder produces worse results. The system rewards non-effort. Still-mind holds lengthen. Direct-knowing probes shift from 30% to 60% of trials.

**Phase C — Ecological integration (sessions 7+):** All task types interleaved unpredictably. No task-type cues. The player must meet each moment without preparation. Scoring shifts entirely to spontaneity indices.

## 5. Infinite Checkpoint & Theta

- **Checkpoint:** Every 90-second block is a complete measurement unit. Player can exit at any block boundary.
- **Theta-decay:** Half-life 28 days. Decay manifests as return of effort-signatures in previously effortless domains.
- **Session length:** Player-determined. Minimum meaningful session: 3 minutes (2 blocks).
- **Felt-sense reward:** The game becomes easier as the player releases grasping — difficulty is constant but subjective effort decreases. This IS the reward.
