# Cognitive / Turquoise — Deterministic

## 1. Game Identity

| Field | Value |
|---|---|
| Modality | Deterministic (fixed-mechanics, objective scoring) |
| Unique probe | Objective vision-logic measurement — meta-WCST accuracy, recursive planning depth, n=4 holonic working-memory span |
| Core loop | Player executes cognitive tasks requiring thinking-about-thinking: rules that govern rules, plans nested within plans, memory structures that hold wholes |
| Session length | 4–12 minutes (infinite checkpoint) |

## 2. Mechanics

### 2.1 Meta-WCST (Rules-About-Rules)

Cards sort by a visible rule. Mid-trial, the rule-selection-rule shifts (not just the rule itself). Player must detect WHICH LEVEL changed — the sort dimension, or the meta-rule governing dimension-selection. Recursive depth: rule → meta-rule → meta-meta-rule (3 levels). Accuracy and switch-cost at each level scored independently.

### 2.2 Holonic n=4 Working Memory

Four simultaneous streams, each a holon (part/whole). Player tracks items that are BOTH independent sequences AND components of a larger pattern. Scoring: per-stream accuracy × cross-stream integration accuracy. Bonus for detecting emergent cross-stream patterns the whole produces beyond the sum.

### 2.3 Recursive Tower of London

Standard Tower of London, but sub-goals themselves contain Tower-of-London sub-problems. Player must plan at the macro level while solving micro-level planning puzzles that feed into the macro solution. Depth: 2–3 recursive layers. Scored on move-efficiency at each layer and cross-layer coherence.

## 3. Shadow Surfacing

| Shadow | How it appears | Diagnostic signal |
|---|---|---|
| DA (Meta-Mapper) | Over-analyses meta-levels, slow to commit; perfect meta-rule detection but paralysed at execution | High meta-accuracy, high latency, low throughput |
| DAll (Green Pluralist) | Refuses to rank rule-levels; treats all levels as equivalent; flat performance across depths | No improvement at meta-levels; equal error distribution |
| GA (Premature Non-Dualist) | Skips systematic rule-tracking; guesses holistically; occasional brilliant hits, inconsistent | High variance, low sustained accuracy, fast responses |
| GAll (Integral Fortress) | Excellent meta-WCST and recursive planning but freezes when tasks require releasing structure | High accuracy until dissolution-probes; sharp drop at boundary |

## 4. Catalyst → Experience → Integration

**Catalyst:** Tasks escalate from single-level rules to recursive meta-rules. The game FORCES engagement with thinking-about-thinking.

**Experience:** Player feels the difference between mapping and being-in-the-pattern. Meta-Mapper feels paralysis. Green Pluralist feels the cost of refusing hierarchy. Premature Non-Dualist feels inconsistency exposed. Integral Fortress feels the edge where structure must yield.

**Integration:** Adaptive difficulty holds player at their genuine edge. Success requires BOTH meta-cognitive precision AND willingness to act within complexity. The game rewards integrated vision-logic — not just mapping, not just acting, but mapping-while-acting.

## 5. Progression & Infinite Checkpoint

| Phase | Focus | Unlock condition |
|---|---|---|
| Diagnosis | Baseline meta-WCST, n=4, recursive ToL | Entry (stage unlock) |
| Healing | Shadow-specific adaptive sequences | Shadow detected above threshold |
| Evolution | Cross-task integration; all three tasks interleaved | Drive-health > 0.6 across all four drives |
| Maintenance | Theta-decay prevention; shadow-mode encounters | Post-evolution periodic return |

Checkpoints every 90 seconds. Player may leave at any checkpoint. Progress persists. Difficulty adapts continuously via staircase algorithm targeting 75% accuracy at the player's current recursive depth.
