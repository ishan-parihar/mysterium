# Intrapersonal × Turquoise — Deterministic

## 1. Game Identity

- **Modality:** Deterministic (fixed-mechanics, objective measurement)
- **Unique axis:** Objective developmental self-awareness — stage-recognition accuracy, self-process tracking, integration metrics
- **Core mechanic:** Player identifies developmental stages in self-descriptions, tracks own process across time, and demonstrates integration of multiple self-stages into coherent action

## 2. Catalyst Mechanics

### 2.1 Stage-Recognition Tasks
Player is shown self-descriptions (journal entries, internal monologues, behavioral patterns) and must accurately identify which developmental stage each represents. Accuracy reveals whether the player can genuinely SEE stages or merely labels them intellectually.

### 2.2 Self-Process Tracking
Timed sequences where player tracks their own shifting self-states across a session. The system presents micro-moments of self-experience and player must tag: which self is active, what stage it operates from, what drive animates it. Speed and accuracy both scored.

### 2.3 Integration Metrics
Player must demonstrate that identified stages are HELD simultaneously — tasks require acting from one stage while acknowledging another. Measured via response coherence when multiple self-stages are activated in rapid succession.

## 3. Shadow Surfacing

- **DA (Self-Witness Addict):** Over-tagging — player identifies too many meta-layers, adds witnessing layers that aren't present, cannot stop decomposing experience into observed components
- **DAll (Pluralistic Self):** Refuses to integrate — accurately identifies stages but insists they remain separate, scores high on recognition but low on integration tasks
- **GA (Premature No-Self):** Collapses distinctions — claims all stages are 'just awareness,' scores low on recognition because they bypass differentiation
- **GAll (Integral Self Fortress):** Perfect recognition, zero surrender — flawless stage-identification but freezes on tasks requiring release of the witnessing position itself

## 4. Progression Arc

### 4.1 Diagnosis Phase
Baseline stage-recognition accuracy established. System maps which stages player can identify in others vs. self, which they over-identify, which they deny.

### 4.2 Healing Phase
Tasks calibrate toward shadow-specific interventions: DA players get tasks requiring direct action WITHOUT meta-commentary; DAll players get integration tasks that preserve multiplicity while adding coherence.

### 4.3 Evolution Phase
Tasks require genuine vision-logic operation: holding the entire developmental spectrum in awareness while acting from appropriate stage-response. The witness becomes functional rather than addictive or defensive.

## 5. Scoring Integration

- **Primary metric:** Stage-recognition accuracy × integration coherence
- **Drive scoring:** Eros scored via upward-stage recognition; Agape via downward-stage embrace; Agency via decisive integration; Communion via permeable self-boundaries
- **Shadow detection:** Over-tagging frequency (DA), integration-refusal rate (DAll), premature-collapse frequency (GA), surrender-avoidance on release tasks (GAll)
- **Theta-decay:** Half-life 17 days; neglected recognition accuracy degrades, requiring re-calibration
- **Cross-line bonus:** +0.15 when stage-recognition transfers to Cognitive line tasks
