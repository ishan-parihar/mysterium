## 1. Modality Identity

| Field | Value |
|---|---|
| Module | Intrapersonal / White |
| Modality | Language-Reflective |
| Unique lateral | Verbal articulation of non-dual self — how the player talks about self reveals residual grasping |

## 2. Core Mechanic

Open-ended verbal/written prompts that invite the player to describe their experience, identity, or relationship to awareness. LLM-scored rubrics detect residual self-grasping patterns in linguistic structure — pronoun usage, identity claims, negation patterns, and performative non-dual language.

## 3. Shadow Detection

| Shadow | Linguistic signature |
|---|---|
| 2.1 Grasping-at-Self | Persistent first-person ownership ('my awareness', 'I am'); identity-anchoring language |
| 2.2 Aversion-to-Self | Negation-heavy language ('not me', 'no self'); avoidance of self-reference rather than transparent use |
| 2.3 Self-Bypassing | Formulaic non-dual vocabulary ('there is no one here') contradicted by implicit self-positioning in syntax |
| 2.4 Identity-with-Witness | Consistent witness-language ('I observe', 'awareness sees'); subtle subject-position retained |

## 4. Task Architecture

### 4.1 Identity Articulation Prompts
- "Describe who is reading these words right now"
- "What remains when you set aside everything you know about yourself?"
- Adaptive follow-ups based on detected grasping patterns

### 4.2 Paradox Navigation
- Prompts that require speaking about self without reifying it
- "Act in this scenario and then describe who acted"
- Scoring: can the player use language fluidly without getting trapped in self-reference?

### 4.3 Spontaneous Speech Analysis
- During other game activities, incidental self-referential language is tracked
- Ratio of owned vs. transparent action-descriptions
- Consistency between deliberate (prompted) and spontaneous self-language

## 5. Drive Probing

| Drive | Probe |
|---|---|
| Eros | Does language reach toward deeper self-dissolution or circle back to identity? |
| Agape | Does language release self-claims gracefully or perform release while retaining? |
| Agency | Can the player describe decisive action without an agent-subject? |
| Communion | Does language dissolve self-other boundary or maintain subtle separation? |

## 6. Scoring

- Primary: Self-Reification Index — frequency and rigidity of identity-claims in language
- Secondary: Performativity Score — gap between non-dual vocabulary and structural self-positioning
- Tertiary: Fluidity Index — ability to use self-language instrumentally without attachment
- LLM rubric scores calibrated against developmental-stage language corpora

## 7. Catalyst → Experience → Integration

- **Catalyst:** Prompts that make self-reference visible as a linguistic choice rather than necessity
- **Experience:** The player notices how language constructs and maintains self — or doesn't
- **Integration:** Residual grasping becomes audible in one's own speech; hearing it releases it

## 8. Progression

- Entry: Baseline self-language profile established across multiple prompt types
- Middle: Targeted prompts surface specific grasping patterns for examination
- Advanced: Player's language becomes transparent — self-reference used instrumentally, not compulsively
- Infinite: Ongoing tracking ensures linguistic transparency generalises; theta-decay on regression
