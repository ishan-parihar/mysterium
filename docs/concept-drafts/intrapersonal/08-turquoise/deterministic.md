## 1. Modality Identity

| Field | Value |
|---|---|
| Module | Intrapersonal / White |
| Modality | Deterministic |
| Unique lateral | Objective self-transparency measurement — self-reference latency, identity-grasping detection, witness-attachment metrics |

## 2. Core Mechanic

Timed cognitive tasks where self-referential processing is the measured variable. The player performs rapid categorisation, pattern-matching, or response tasks. Stimuli are designed so that self-referential framing creates measurable latency differences compared to transparent (non-self-referential) processing.

## 3. Shadow Detection

| Shadow | Detection method |
|---|---|
| 2.1 Grasping-at-Self | Elevated RT on self-dissolution stimuli vs. neutral; increased error rate when identity is destabilised |
| 2.2 Aversion-to-Self | Avoidance patterns — faster rejection of self-relevant stimuli, selective non-engagement |
| 2.3 Self-Bypassing | Flat RT profile (performed equanimity) contradicted by physiological micro-signatures or downstream choice inconsistency |
| 2.4 Identity-with-Witness | Consistent preference for observer-position stimuli; RT advantage for witness-framed items |

## 4. Task Architecture

### 4.1 Self-Reference Latency Probe
- Rapid word/image categorisation: self-relevant vs. other-relevant vs. universal
- At White, genuine transparency yields no RT difference across categories
- Residual grasping shows as category-specific latency spikes

### 4.2 Identity Dissolution Sequence
- Progressive removal of identity anchors (name, role, body, witness)
- Each removal is a decision-point; hesitation = grasping signal
- Sequence adapts based on where grasping concentrates

### 4.3 Witness-Attachment Metric
- Tasks requiring action FROM different positions (actor, observer, neither)
- Genuine transparency: equal facility from any position
- Witness-identification: performance advantage from observer position

## 5. Drive Probing

| Drive | Probe |
|---|---|
| Eros | Does the player reach toward self-dissolution or resist it? |
| Agape | Does the player release identity gracefully or cling? |
| Agency | Can the player act decisively without a self claiming the action? |
| Communion | Can the player merge with task-flow without losing functional coherence? |

## 6. Scoring

- Primary: Self-Reference Effect magnitude (lower = more transparent)
- Secondary: Position-independence index (equal performance across frames)
- Tertiary: Consistency across sessions (genuine vs. performed transparency)
- All scores feed drive-health (weight 0.35) and shadow-drag (0.15)

## 7. Catalyst → Experience → Integration

- **Catalyst:** Tasks that make self-reference optional — the player can solve them with or without 'I'
- **Experience:** Noticing the difference between self-referential and transparent processing in real-time
- **Integration:** Residual grasping patterns become visible through their latency signatures; visibility itself dissolves them

## 8. Progression

- Entry: Baseline self-reference effect established
- Middle: Adaptive difficulty targets specific grasping patterns
- Advanced: Tasks become indistinguishable from ordinary cognition — transparency is the default
- Infinite: Periodic re-probing ensures no regression; theta-decay triggers re-engagement
