# Willpower × Turquoise — Strategic-Planning

## 1. Core Mechanic

The player constructs **Holonic Goal Architectures Across Time** — multi-session planning tasks where evolutionary purpose must be translated into nested temporal commitments. Unlike deterministic (which measures spatial/logical accuracy of arrangement), strategic-planning measures the capacity to structure will across timescales while maintaining coherence at every level.

### 1.1 Task Structure

- **Temporal Nesting:** Given an evolutionary purpose, player constructs: decade-goals → year-goals → month-goals → week-goals → today's action. Each level must serve the one above while being executable at its own scale.
- **Adaptive Re-Architecture:** Mid-plan disruptions require restructuring without losing evolutionary coherence. The plan changes; the purpose holds.
- **Resource Allocation:** Limited will-energy distributed across holonic levels — over-investing in architecture starves execution; over-investing in execution loses coherence.
- **Milestone Sequencing:** Ordering developmental milestones so each enables the next — the strategic logic of integral will.

### 1.2 Evaluation Criteria

- Vertical coherence: does each level genuinely serve the one above?
- Horizontal completeness: are all necessary sub-goals present at each level?
- Temporal realism: are timescales appropriate to the goal-magnitude?
- Adaptability: does the architecture survive perturbation without collapse?

## 2. Shadow Diagnostics

| Shadow | Planning Pattern |
|---|---|
| DA (Will-Architect) | Infinite recursion — keeps adding sub-levels, never reaches executable granularity; the plan becomes the purpose |
| DAll (Collaborative Pluralist) | Flat timeline — all goals at same temporal scale; refuses hierarchical sequencing; "everything is equally urgent" |
| GA (Premature Surrenderer) | Skips planning entirely; places "trust the process" at every level; no concrete architecture |
| GAll (Integral Will Fortress) | Rigid plan with no adaptation pathways; refuses contingency; "the architecture is perfect as designed" |

### 2.1 Detection Metrics

- DA: plan-depth > 7 levels with no executable actions at leaf nodes
- DAll: temporal variance < 0.2 (all goals clustered in same timeframe)
- GA: plan-completeness < 30% (most levels empty or vague)
- GAll: contingency-pathways = 0; adaptation-score < 0.15

## 3. Catalyst → Experience → Integration

**Catalyst:** A genuinely complex evolutionary purpose that cannot be achieved through simple linear planning — requires holonic architecture. Then: disruption that demands restructuring without abandoning purpose.

**Experience:** The felt-sense of strategic integral will — the moment when the architecture serves rather than constrains, when planning becomes an expression of will rather than a substitute for it.

**Integration:** Plans created in-game become reference architectures the player can revisit. The system tracks plan-execution alignment over sessions — did the player follow through? Did adaptation serve or undermine coherence?

## 4. Progression Arc

1. **Diagnosis (sessions 1–3):** Baseline planning capacity; shadow identification through planning style
2. **Healing (sessions 4–10):** Targeted challenges — forced execution deadlines (DA), forced prioritisation (DAll), forced architecture (GA), forced adaptation (GAll)
3. **Evolution (sessions 11+):** Multi-session plans spanning real time — the game tracks whether actual engagement matches stated architecture

### 4.1 Mastery Indicators

- 5+ level temporal architecture with executable leaf-nodes
- Adaptation-score ≥ 0.7 after perturbation
- Plan-execution alignment ≥ 0.6 across sessions
- Resource allocation balanced across levels (no single level > 40% of will-energy)
