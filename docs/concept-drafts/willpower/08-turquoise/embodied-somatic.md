## 2. Catalyst Design

The player performs physical actions (touch, gesture, rhythm, breath-gated movement). The system measures somatic signatures of effortless will vs. residual grasping — muscular over-recruitment, breath-holding, tension patterns, and force excess reveal where the body still "tries."

### 2.1 Somatic Transparency Metrics
- **Force calibration:** minimum-necessary force vs. excess (efforting body = excess force)
- **Breath continuity:** breath flows through action vs. holds during action (grasping = holding)
- **Movement initiation:** action begins from centre vs. periphery (doer-identity = peripheral initiation)
- **Recovery signature:** immediate release after action vs. residual tension (outcome-grasping = lingering tension)

### 2.2 Embodied Surrender Indicators
- Action and rest are indistinguishable in quality
- Movement has no "trying" signature — smooth onset, smooth offset
- Body responds to stimulus without preparatory bracing
- Force matches task exactly — no surplus, no deficit

## 4. Progression Architecture

### 4.1 Diagnosis Phase
Baseline movement sequences across varied action types. System maps somatic grasping topology — which body regions hold, which action types trigger strain, which residual patterns dominate.

### 4.2 Healing Phase
Movement sequences tailored to the player's somatic grasping patterns. Outcome-graspers practice actions with no feedback. Avoiders practice gentle exposure to avoided movement types. Bypassers practice actions requiring genuine physical engagement. The movement itself is the healing.

### 4.3 Evolution Phase
All movement types presented in rapid succession. System measures whether somatic transparency has generalised — uniform force calibration, continuous breath, immediate release across all action categories.

## 6. Scoring

Somatic transparency index (0–1) per movement sequence. Force-calibration error, breath-continuity score, initiation-quality, and recovery-speed scored independently. Drive-balance = directional force variance. Half-life 28 days; max decay 10%.

## 7. Infinite Checkpoint

Each movement sequence is a checkpoint. Player can leave between sequences. No sequence depends on prior sequences. State saved continuously. Compound shadow "The Passive Avoider" (Willpower × Somatic) is primary detection target.
