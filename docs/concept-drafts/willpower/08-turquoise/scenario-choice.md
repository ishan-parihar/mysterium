## 1. Modality Identity

| Field | Value |
|---|---|
| Module | Willpower × White |
| Modality | Scenario-Choice |
| Unique Lateral | Non-dual will dilemmas — situations requiring action without attachment to outcome |
| Core Mechanic | Branching scenarios where every option succeeds but reveals residual grasping in how the choice is made |

## 2. Catalyst Design

The player faces scenarios where action is required but no outcome is better than another. The diagnostic signal is not *what* the player chooses but *how* they choose — the quality of will behind the decision. Hesitation patterns, justification needs, and post-choice behaviour reveal residual grasping.

### 2.1 Non-Dual Dilemma Structure
- All options are equally valid — no "right answer"
- The scenario requires genuine action (inaction is not an option)
- Outcomes are not revealed (removing outcome-attachment leverage)
- The player's choice-process itself is the data

### 2.2 Choice-Quality Metrics
- **Decision latency profile:** not speed but pattern — uniform latency = equanimous; variable = residual preferences
- **Justification seeking:** does player look for reasons, or act from clarity?
- **Post-choice revisitation:** does player return to unchosen options mentally?
- **Choice-consistency across equivalent scenarios:** stable will vs. reactive will

## 3. Shadow Probes

| Shadow | Scenario Type |
|---|---|
| 2.1 Grasping-at-Outcome | Scenarios where outcomes are explicitly unknowable — does player still try to optimise? |
| 2.2 Aversion-to-Action | Scenarios where all options require action in a domain the player avoids |
| 2.3 Will-Bypassing | Scenarios where "surrender" is an option — does player choose it to avoid genuine engagement? |
| 2.4 Identity-with-Doer | Scenarios where the action is attributed to the player vs. "happening through" them |

## 4. Progression Architecture

### 4.1 Diagnosis Phase
Baseline scenarios across all four shadow domains. System maps the player's residual grasping topology — which patterns are strongest, in which contexts.

### 4.2 Healing Phase
Scenarios are tuned to the player's specific residual patterns. Outcome-graspers face scenarios where outcomes are progressively more unknowable. Bypassers face scenarios where genuine engagement is the only path. Each scenario is itself a practice of transparent will.

### 4.3 Evolution Phase
Scenarios become indistinguishable from ordinary life situations. The system measures whether equanimous choice-quality has generalised. Choice-process metrics should converge across all scenario types.

## 5. Drive Detection

| Drive | Choice Signal |
|---|---|
| Eros | Consistently chooses growth-oriented options (residual upward pull) |
| Agape | Consistently chooses release-oriented options (residual downward pull) |
| Agency | Consistently chooses self-expressive options (residual self-assertion) |
| Communion | Consistently chooses other-serving options (residual self-dissolution) |

## 6. Scoring

Choice-quality index (0–1) per scenario. Residual grasping scored per shadow quadrant. Drive-balance = variance in option-type preferences across equivalent scenarios. Half-life 28 days; max decay 10%.

## 7. Infinite Checkpoint

Each scenario is a checkpoint. Player can leave between scenarios. No scenario depends on prior choices. State saved per completed scenario.
