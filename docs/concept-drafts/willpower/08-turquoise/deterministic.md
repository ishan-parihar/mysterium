## 1. Modality Identity

| Field | Value |
|---|---|
| Module | Willpower × White |
| Modality | Deterministic |
| Unique Lateral | Objective effortless-will measurement — action-without-strain metrics, outcome-attachment detection |
| Core Mechanic | Timed action sequences where strain, hesitation, and outcome-checking are measured instrumentally |

## 2. Catalyst Design

The player performs goal-directed action sequences. The system measures not success/failure but the *quality of action itself* — strain signatures, micro-hesitations, outcome-checking behaviours, and post-action attachment patterns.

### 2.1 Action-Without-Strain Metrics
- **Initiation latency:** delay between stimulus and action onset (residual aversion = high latency on specific action-types)
- **Execution smoothness:** jitter, correction frequency, force variability (residual efforting = high correction)
- **Completion release:** how quickly attention releases from completed action (residual outcome-grasping = lingering)

### 2.2 Outcome-Attachment Detection
- **Result-checking frequency:** how often player revisits completed actions
- **Success-contingent behaviour shift:** does player's action quality change based on prior outcomes?
- **Failure-recovery signature:** does failure produce strain increase or equanimous continuation?

## 3. Shadow Probes

| Shadow | Probe |
|---|---|
| 2.1 Grasping-at-Outcome | Post-action dwell time; success-contingent strain increase |
| 2.2 Aversion-to-Action | Category-specific initiation delays; avoidance of certain action types |
| 2.3 Will-Bypassing | Low initiation latency but high execution jitter (performing ease while efforting) |
| 2.4 Identity-with-Doer | Self-referential micro-pauses before action; agency-signalling behaviours |

## 4. Progression Architecture

### 4.1 Diagnosis Phase
Baseline action sequences establish individual strain profile. System identifies which residual patterns are present and their magnitude.

### 4.2 Healing Phase
Sequences are tuned to the player's specific residual patterns. Outcome-graspers receive tasks where outcomes are hidden. Action-avoiders receive gentle exposure to avoided categories. Bypassers receive tasks requiring genuine ease.

### 4.3 Evolution Phase
All action categories presented simultaneously. The system measures whether equanimous action has generalised across all domains. Strain signatures should converge toward zero differential.

## 5. Drive Detection

| Drive | Residual Signal |
|---|---|
| Eros | Strain increases on growth-oriented actions (still pushing upward) |
| Agape | Strain increases on release-oriented actions (still holding) |
| Agency | Strain increases on self-initiated actions (still claiming) |
| Communion | Strain increases on responsive actions (still merging) |

## 6. Scoring

Action-without-strain index (0–1) computed per session. Residual grasping patterns scored independently. Drive-balance computed as variance across four drive-strain scores. Half-life 28 days; max decay 10%.

## 7. Infinite Checkpoint

Each action sequence is a checkpoint. Player can leave between any two sequences. No sequence depends on prior sequences. State saved continuously.
