# Spiritual / Red — Module Specification Skeleton

---

## 1. Capacity Definition

**Transactional meaning-making** — the first stable relationship to "ultimate concern" where the sacred is PERSONAL and POWER-GRANTING. At Red, spiritual intelligence is: "What do I value most? What gives me power? What is sacred TO ME?" The relationship to the sacred is egocentric and transactional: "I serve the power-deity; the power-deity serves me."

### Core capacities (Red ceiling)

| Capacity | Description | Red ceiling |
|---|---|---|
| Value-identification | "X matters most to me" — naming ultimate concern | Concrete, egocentric ("Power matters most"; "Victory matters most") |
| Value-coherence | Acting in alignment with stated value under pressure | Short-burst coherence (holds value for 1-2 decisions under load) |
| Transactional faith | "If I serve X, X serves me" — reciprocal sacred relationship | Concrete exchange ("I honour strength; strength honours me") |
| Priority-under-load | Choosing primary value when multiple compete | Binary priority (this OR that; no synthesis) |
| Sacred-boundary | "This is sacred to me; violating it costs" | Concrete, personal ("My weapon is sacred"; "My word is sacred") |

### What is NOT yet available (above Red)

- Mythic-membership faith ("Our tradition is the true way") — requires Amber group-belonging
- Rational questioning of faith ("Is my value justified?") — requires Orange
- Pluralistic acceptance ("All paths are valid") — requires Green
- Integral synthesis ("Paths are facets of one architecture") — requires Teal
- Surrender/non-grasping — requires Teal+
- Value-hierarchy REVISION based on depth — requires Orange+

### The Spiritual/Red character

The sacred at Red is PERSONAL and POWER-GRANTING. It's not institutional religion (Amber) or rational principle (Orange). It's: "I have a power-deity. My power-deity is ON MY SIDE. I serve it and it makes me strong." This can be literal (a war-god) or secular (strength itself as sacred, victory as ultimate concern). The key: it's EGOCENTRIC, TRANSACTIONAL, and CONCRETE.

## 2. Shadow Archetypes

### 2.1 Dark-Addiction: "The Zealot"

**Core pattern:** Over-identified with the power-deity/sacred value to the point where the sacred becomes a WEAPON. "My god demands I destroy you." The value-hierarchy doesn't organise the self — it POSSESSES the self. The sacred serves domination, not meaning.

**Drive pathology:**
- Agency: The sacred is MY weapon; I wield it against others
- Communion: Cannot share the sacred; "My god, not yours"
- Eros: Cannot question or deepen the sacred; it's FIXED and ABSOLUTE
- Agape: Cannot return to simple value-identification; everything is CRUSADE

**Behavioural signatures:**
- Value-invocation is always aggressive (invokes to dominate, never to align)
- Sacred-boundary defence is OFFENSIVE (attacks anyone near the sacred, not just defends)
- Cannot tolerate others' values; "My value is the ONLY value"
- Value-coherence is HIGH but RIGID — never questions, never revises
- Transactional faith is one-directional: demands from the sacred without genuine service
- All actions framed as sacred duty; no secular space remains

**Surfacing conditions:**
- Present a situation where the player's value conflicts with another's
- Present a temptation to use the sacred as a weapon
- Present a situation where the sacred doesn't serve power
- The Zealot responds with: aggression, crusade-framing, or sacred-weaponisation

**What "healed" looks like:**
- Value-invocation serves alignment, not domination
- Sacred-boundary is defensive, not offensive
- Can acknowledge others' values without threat
- Value-coherence is stable but not rigid

---

### 2.2 Dark-Allergy: "The Nihilist"

**Core pattern:** Refuses all value-hierarchy. "Nothing matters. It's all meaningless." The spiritual line is EMPTY — not because they've transcended values (that's Teal+) but because they refuse to commit to any. Spiritual emptiness as defence against the vulnerability of caring.

**Drive pathology:**
- Agency: Cannot name what matters; "I don't have values"
- Communion: Cannot share values because they claim to have none
- Eros: Cannot grow spiritually because there's nothing to grow FROM
- Agape: Cannot maintain value-coherence because no values are held

**Behavioural signatures:**
- Cannot name a primary value when asked
- Actions show no value-coherence (random, opportunistic, or purely survival-driven)
- Dismisses value-identification tasks: "This is pointless"
- No sacred-boundary exists (nothing is protected)
- No transactional faith (no relationship to anything beyond self)
- May be highly functional in other lines but spiritually hollow

**Surfacing conditions:**
- Present a value-identification task ("What matters most to you?")
- Present a sacred-boundary opportunity ("Is anything sacred to you?")
- Present a situation where having a value would produce advantage
- The Nihilist responds with: dismissal, "nothing," or cynical deflection

**What "healed" looks like:**
- Can name ONE thing that matters (even if simple: "winning," "my weapon," "my word")
- Actions show SOME value-coherence (even minimal)
- Acknowledges that SOMETHING is sacred (even if small)
- Engages transactional faith at any level

---

### 2.3 Golden-Addiction: "The Premature Mystic"

**Core pattern:** Performs HIGHER spiritual capacity without Red grounding. Claims "I've transcended values" or "All paths are one" — but has never committed to a SINGLE value at Red. The transcendence is premature because there's nothing to transcend. Spiritual bypass of the Red power-sacred.

**Drive pathology:**
- Agency: Cannot commit to a sovereign value; "I'm beyond choosing"
- Communion: Joins "spiritual" communities without personal sacred commitment
- Eros: Reaches for Teal/Turquoise without Red/Amber/Orange foundation
- Agape: Cannot return to simple value-identification; "That's too basic for me"

**Behavioural signatures:**
- Uses advanced spiritual language ("non-dual," "surrender," "pathless path")
- But cannot name a concrete primary value
- Value-coherence is LOW (no value to be coherent with)
- Claims to have "transcended" the transactional sacred
- Cannot engage simple value-identification tasks (too "evolved")
- Cross-validation: language-reflective HIGH + deterministic LOW
- No sacred-boundary (claims "nothing needs protecting because all is sacred")

**Surfacing conditions:**
- Present a concrete value-identification task ("Name ONE thing that matters most")
- Present a sacred-boundary task ("What would you protect?")
- Present a situation requiring value-commitment (choose and hold)
- The Premature Mystic responds with: abstract spiritual language, refusal to commit, or "transcendence" claims

**What "healed" looks like:**
- Can name a concrete primary value and MEAN it
- Value-coherence is demonstrable (actions match stated value)
- Engages transactional faith genuinely (serves and receives)
- Sacred-boundary exists (something concrete is protected)
- THEN (and only then) can genuine transcendence begin

---

### 2.4 Golden-Allergy: "The Sacred-Refuser"

**Core pattern:** Terrified of committing to a value because commitment feels like DEATH OF FREEDOM. "If I say X matters most, I'm trapped." The Red ego, which values freedom and power above all, experiences value-commitment as a cage. They COULD commit but WON'T because commitment = loss of power.

**Drive pathology:**
- Agency: Hyper-sovereign; "I won't be bound by any value"
- Communion: Cannot share values because sharing = being bound
- Eros: Refuses the developmental edge (value-commitment) because it constrains
- Agape: Cannot maintain any value because maintenance = imprisonment

**Behavioural signatures:**
- CAN identify values (unlike the Nihilist) but WON'T commit
- Starts value-coherence but abandons quickly ("I changed my mind")
- Sacred-boundary is declared then immediately violated ("I said it was sacred but...")
- Transactional faith is attempted then broken ("I served but then I stopped")
- High freedom-seeking; low commitment-tolerance
- Values CHANGE frequently (not deepening — just switching)
- The difference from Nihilist: the Sacred-Refuser FEELS the pull of the sacred but REFUSES it

**Surfacing conditions:**
- Present a value-commitment task (hold this value for 3 decisions)
- Present a sacred-boundary that requires sustained defence
- Present a transactional faith that requires sustained service
- The Sacred-Refuser responds with: initial engagement then abandonment; "I don't want to be locked in"

**What "healed" looks like:**
- Can commit to a value for sustained periods without feeling trapped
- Sacred-boundary is maintained (not declared then violated)
- Transactional faith is sustained (serves and receives over time)
- Commitment is experienced as POWER (not as cage)

## 3. Drive-Health Landscape

| Drive | Weight | Rationale |
|---|---|---|
| Agency | 0.35 | Spiritual at Red is primarily SOVEREIGN — "MY value, MY sacred, MY power-deity" |
| Communion | 0.15 | Minimal relational spirituality at Red (shared faith comes at Amber) |
| Eros | 0.25 | The developmental edge — can they reach toward deeper values? |
| Agape | 0.25 | Can they maintain value-coherence over time? Return to the sacred? |

**Total drive-health weight for consciousness index:** 0.30

### Rationale for 0.30
Spiritual is the "why" line — it organises all other lines around ultimate concern. But at Red, its contribution is modest because the capacity is primitive (transactional, egocentric). Its weight increases at Amber+ where value-coherence becomes the organising principle of the whole personality.

## 4. Healing Vectors

### 4.1 For Dark-Addiction (The Zealot)

**Vector:** Agape + Agency (return to simple value-identification with sovereign honesty)

**Mechanism:**
1. Present situations where the sacred REQUIRES restraint (not aggression)
2. Frame: "Your power-deity demands you PROTECT, not destroy. Can you serve THAT way?"
3. Reward value-coherence that serves alignment over domination
4. Gradually: the sacred becomes a source of MEANING, not just a weapon

### 4.2 For Dark-Allergy (The Nihilist)

**Vector:** Agape + Agency (return to value-identification with sovereign courage)

**Mechanism:**
1. Present situations where HAVING a value produces tangible power
2. Frame: "The warrior with a cause fights harder than the one without. Name your cause."
3. Start with TINY value-commitments ("For this ONE fight, what matters?")
4. Gradually: small values → sustained values → the nihilist discovers that meaning is power

### 4.3 For Golden-Addiction (The Premature Mystic)

**Vector:** Eros + Communion (reach for genuine capacity through honest grounding)

**Mechanism:**
1. Require CONCRETE value-identification (not abstract "all is one")
2. Cross-validate: does the "transcendence" produce value-coherence? (It won't)
3. Frame: "Before you transcend values, HAVE one. Name it. Hold it. THEN transcend."
4. Gradually: concrete value → sustained coherence → genuine depth → THEN transcendence is real

### 4.4 For Golden-Allergy (The Sacred-Refuser)

**Vector:** Eros + Communion (reach for commitment through safe joining)

**Mechanism:**
1. Make value-commitment TEMPORARY and REVERSIBLE ("Hold this value for 3 decisions. Then you're free.")
2. Frame: "Commitment isn't a cage. It's a WEAPON. The warrior with a cause is STRONGER."
3. Start with SHORT commitments; extend gradually
4. Gradually: short commitment → longer → sustained → the sacred-refuser discovers that commitment is power, not prison

## 5. Scoring Parameters

| Parameter | Value | Rationale |
|---|---|---|
| Half-life | 20 days | Slow. Spiritual altitude is event-driven, not session-driven. Values are stable once established. |
| Max decay | 15% | Cannot lose more than 15% — values don't disappear, they just lose coherence |
| Decay curve | Exponential | Standard |
| Recovery rate | 1.1× | Slow recovery — spiritual coherence rebuilds gradually |
| Practice sensitivity | MODERATE | Value-coherence practice arrests decay; casual play doesn't |

### Decay-arrest conditions
- Any value-invocation (stating primary value under load) arrests decay
- Value-coherent action (acting in alignment with stated value) arrests decay
- Sacred-boundary defence (protecting what's sacred) arrests decay
- Transactional faith engagement (serving the sacred and receiving) arrests decay

## 6. Compound Shadows & Cross-Module Relationships

### 6.1 The Holy Warrior (Spiritual + Willpower)

**Loop:** Spiritual dark-addiction (zealotry) + Willpower dark-addiction (compulsive pursuit) = fanatical, unstoppable pursuit of sacred goal. The will serves the weaponised sacred without question. Crusade-mode.

**Detection:** High spiritual engagement (but aggressive) + high willpower (but rigid). All effort serves the sacred weapon. Cannot stop, cannot question.

**Breaking the loop:** Present situations where the sacred goal REQUIRES restraint. "Your god demands you WAIT. Your god demands you show mercy. Can your will serve THAT?"

### 6.2 The Meaning-Void (Spiritual + Intrapersonal)

**Loop:** Spiritual dark-allergy (nihilism) + Intrapersonal dark-allergy (unexamined) = no values AND no self-knowledge. Drifting without anchor or mirror. Cannot say what matters because they don't know themselves, and don't know themselves because nothing matters enough to look.

**Detection:** Zero spiritual engagement + zero intrapersonal engagement. No values, no self-knowledge. Functional but hollow.

**Breaking the loop:** Start with the BODY (somatic entry). The body has preferences even when the mind refuses. "Your body chose to protect that. Something matters. What?"

### 6.3 The Spiritual Bypasser (Spiritual + Intrapersonal)

**Loop:** Spiritual golden-addiction (premature transcendence) + Intrapersonal golden-addiction (premature witness) = performs "enlightened awareness" without Red grounding in either line. Claims transcendence of both self and values without ever having either.

**Detection:** Sophisticated spiritual + intrapersonal language + LOW concrete capacity in both. Sounds awakened but can't name a value or predict own behaviour.

**Breaking the loop:** Require CONCRETE Red demonstrations. "Before you transcend values, HAVE a value. Before you witness the self, KNOW the self. Ground first."

### 6.4 The Power-Atheist (Spiritual + Cognitive)

**Loop:** Spiritual dark-allergy (nihilism) + Cognitive dark-addiction (intellectualisation) = uses cognitive power to JUSTIFY spiritual emptiness. "Values are irrational. Meaning is a construct. I'm too smart for faith." Intelligence weaponised against the sacred.

**Detection:** High cognitive engagement + zero spiritual engagement. Articulate dismissal of all value-hierarchy. "Meaning is a cognitive bias."

**Breaking the loop:** Present situations where COGNITIVE SUCCESS requires value-commitment. "Your strategy needs a goal. What matters enough to plan for? Intelligence without direction is noise."

## 7. Shadow Surfacing Sequence

The game surfaces shadows in a specific developmental order:

```
1. Value-identification → Can they name what matters most?
   ├─ If weaponised → Zealot pathway
   ├─ If absent/refused → Nihilist pathway
   ├─ If abstract/transcendent → Premature Mystic pathway
   └─ If present and concrete → proceed

2. Value-coherence → Do actions align with stated value?
   ├─ If rigid/aggressive → Zealot pathway
   ├─ If absent (no value to align with) → Nihilist pathway
   ├─ If claimed but not demonstrated → Premature Mystic pathway
   ├─ If started then abandoned → Sacred-Refuser pathway
   └─ If sustained and genuine → proceed

3. Transactional faith → Do they engage the sacred reciprocally?
   ├─ If one-directional/demanding → Zealot pathway
   ├─ If absent → Nihilist pathway
   ├─ If performed without genuine engagement → Premature Mystic pathway
   ├─ If engaged then broken → Sacred-Refuser pathway
   └─ If genuine and sustained → proceed

4. Sacred-boundary → Do they protect what's sacred?
   ├─ If offensive/weaponised → Zealot pathway
   ├─ If nothing is sacred → Nihilist pathway
   ├─ If "everything is sacred" (nothing specific) → Premature Mystic pathway
   ├─ If declared then violated → Sacred-Refuser pathway
   └─ If defended appropriately → proceed

5. Priority-under-load → Can they choose between competing values?
   ├─ If always chooses domination → Zealot pathway
   ├─ If cannot choose (nothing matters) → Nihilist pathway
   ├─ If claims "all values are equal" → Premature Mystic pathway
   ├─ If chooses then regrets/switches → Sacred-Refuser pathway
   └─ If chooses clearly and holds → healthy
```
