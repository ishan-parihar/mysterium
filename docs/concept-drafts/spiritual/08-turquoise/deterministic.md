## 1. Modality Identity

| Field | Value |
|---|---|
| Module | Spiritual / White |
| Modality | Deterministic |
| Probe axis | Sacred-ordinary discrimination (target: ZERO), state-attachment detection |
| Core mechanic | Objective measurement of whether player treats any stimulus as more/less sacred |

## 2. Diagnostic Target

Non-dual presence means zero discrimination between sacred and ordinary. The deterministic modality measures this directly through reaction-time differentials, attention allocation, and preference signals when stimuli vary along a sacred-ordinary axis.

## 3. Task Architecture

### 3.1 Sacred-Ordinary Discrimination Task

Player responds to stimuli drawn from two pools: conventionally "sacred" (mandalas, chants, temples, silence) and conventionally "ordinary" (traffic, dishes, spreadsheets, noise). Healthy non-dual = identical response profiles across both pools.

- **Metric:** RT differential between sacred/ordinary stimuli (target: 0ms)
- **Metric:** Attention dwell-time differential (target: 0ms)
- **Metric:** Approach/avoid bias across pools (target: flat)

### 3.2 State-Attachment Detection

Player encounters sequences that induce meditative/flow states, then are interrupted. Measurement: recovery speed and affective response to interruption.

- **Metric:** Frustration signal on state-interruption (target: zero)
- **Metric:** Grasping-at-return latency (how quickly player seeks to re-enter state)
- **Metric:** Performance stability across state transitions

### 3.3 Preference-Absence Verification

Forced-choice between "spiritual" and "mundane" options where both are functionally equivalent. Any systematic preference reveals residual grasping or aversion.

## 4. Shadow Mapping

| Shadow | Detection signal |
|---|---|
| 2.1 Grasping-at-Sacred | RT advantage for sacred stimuli, dwell-time bias toward numinous |
| 2.2 Aversion-to-Sacred | Avoidance patterns for certain sacred depths, faster dismissal |
| 2.3 Spiritual Bypassing | Flat surface metrics but micro-hesitations on "ordinary" stimuli |
| 2.4 Seeker-Identity | Systematic preference for spiritual options in forced-choice |

## 5. Drive Probes

| Drive | Probe | Healthy signal |
|---|---|---|
| Eros | Response to stimuli suggesting "higher" states | No preferential orientation |
| Agape | Response to stimuli suggesting "lower/basic" states | No aversion or condescension |
| Agency | Action initiation across sacred/ordinary contexts | Equal engagement |
| Communion | Receptivity across sacred/ordinary contexts | Equal openness |

## 6. Progression Logic

- **Diagnosis:** Establish baseline discrimination scores across all axes
- **Catalyst:** Present increasingly subtle sacred-ordinary distinctions
- **Integration:** Scores converge toward zero differential; residual bias triggers targeted re-exposure

## 7. Infinite Checkpoint

Each session yields a discrimination profile. Player can leave at any checkpoint. The game never signals "you are non-dual now" — that would itself create grasping. Progress is invisible to the player; only the felt-sense of equanimity remains.

## 8. Adaptive Difficulty

Difficulty = subtlety of sacred-ordinary distinction. Early: obvious (temple vs. office). Late: micro-distinctions (breath-awareness vs. ordinary breathing). The game finds the threshold where discrimination re-emerges.
