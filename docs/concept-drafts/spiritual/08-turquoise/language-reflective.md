## 1. Modality Identity

| Field | Value |
|---|---|
| Module | Spiritual / White |
| Modality | Language-Reflective |
| Probe axis | How player talks about the sacred reveals residual grasping |
| Core mechanic | LLM-scored verbal/written expression analyzed for non-dual markers |

## 2. Diagnostic Target

Language is the subtlest betrayer of residual duality. A player who has truly integrated non-dual presence speaks of the sacred and ordinary with identical weight, without elevation or deflation. This modality detects micro-grasping through linguistic markers.

## 3. Linguistic Markers of Residual Grasping

### 3.1 Elevation Language (Shadow 2.1)

- Superlatives applied to spiritual experience ("the MOST profound," "truly sacred")
- Hierarchical framing ("higher" states as better, "deeper" as more real)
- Specialness markers ("unlike anything else," "beyond words")

### 3.2 Avoidance Language (Shadow 2.2)

- Deflection from mystery ("I don't go there," "that's too much")
- Intellectualization as shield ("theoretically," "one could say")
- Truncated responses when sacred depths are probed

### 3.3 Performance Language (Shadow 2.3)

- Non-dual jargon without embodiment ("all is one," "no self" as rote)
- Contradiction between stated view and linguistic structure
- Over-signaling of equanimity ("I'm totally fine with either")

### 3.4 Identity Language (Shadow 2.4)

- Self-referencing as spiritual agent ("I practice," "my path," "I've realized")
- Narrative of attainment ("since my awakening," "at this point in my journey")
- Subtle ownership of non-dual insight

## 4. Task Architecture

### 4.1 Open Reflection Prompts

Player responds to prompts about ordinary and sacred moments. LLM rubric scores for elevation differential, avoidance patterns, performance markers, identity-grasping.

### 4.2 Completion Tasks

Sentence stems that invite either grasping or transparency: "The sacred is..." / "When I meditate..." / "Ordinary life feels..."

### 4.3 Dialogue with NPCs

NPCs ask about spiritual life. Player's natural conversational responses are scored. NPCs never signal what the "right" answer is.

## 5. Drive Detection via Language

| Drive | Linguistic signal | Residual imbalance |
|---|---|---|
| Eros | Language about growth/transcendence | Over-reaching, future-orientation |
| Agape | Language about acceptance/descent | Performed acceptance, subtle aversion |
| Agency | Language about action/will | Doer-identity in spiritual context |
| Communion | Language about connection/unity | Merger-language, boundary-loss |

## 6. LLM Rubric Structure

The LLM operates within fixed rubric dimensions:
- Sacred-ordinary elevation differential (0–1 scale, target: 0)
- Jargon-to-embodiment ratio (high jargon = performance)
- Self-reference density in spiritual context (high = identity-grasping)
- Mystery-tolerance (truncation/deflection = aversion)

## 7. Progression Logic

- **Diagnosis:** Baseline linguistic profile across all four shadow axes
- **Catalyst:** Prompts that specifically invite the player's residual grasping pattern
- **Integration:** Language naturally equalizes; sacred and ordinary described with same texture

## 8. Design Constraint

The game never teaches "correct" non-dual language. That would create a new performance target. It only measures the natural texture of expression and allows the player's own integration to shift it organically.
