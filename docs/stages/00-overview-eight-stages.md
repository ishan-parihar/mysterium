# stages/00 — Eight Stages Overview

> **Cross-references:** [[docs/foundations/02-eight-stages-overview|02 — Eight Stages Overview]] · [[docs/foundations/06-law-of-one-correspondence|06 — Law Of One Correspondence]]

## 1. Purpose

Establish how the eight stage-of-consciousness documents work. Each
`stages/01-…08-…` file is a *world bible* — the design canon for a
single stage as a playable level / world / arc. This overview is the
chassis those eight documents bolt onto.

The promise of the stages layer:

> By the end of stage 08, a reader can stand inside any stage's world
> and answer "what does cognitive look like here? what does the music
> sound like? what does a side-character do? what does the boss test?"
> *without* re-reading any other section of `/docs/`.

A stage doc that requires the reader to pivot back to `lines/*` to
understand a feature has failed.

## 2. Scientific basis

This document inherits all sourcing from `foundations/02-eight-stages-overview.md`.
It does not re-litigate the eight-stage choice. It only specifies how
each stage's *world bible* is structured.

## 3. The world-bible template

Every `stages/0X-*.md` document has the same nine sections:

```
1. Purpose
2. Stage definition         (psychology, sociology, history, energetics)
3. The eight lines AT this stage   (one paragraph per line; "what does X look like here?")
4. AQAL quadrant snapshots         (UL, UR, LL, LR — what is the world's interior, behaviour, culture, system?)
5. World aesthetic
   5.1 Visual language
   5.2 Sonic language
   5.3 Narrative tone
6. Bestiary at this stage
   6.1 Side-character concepts (one per line — eight archetypes)
   6.2 Mini-boss concepts     (dual-line interference)
   6.3 Main-boss concept      (synthesis exam — touches all 8 lines, all 4 quadrants)
   6.4 Shadow concept         (the typical fixation/regression/repression of THIS stage)
7. Stage advancement criteria      (what the player must demonstrate)
8. Open questions
9. Principles served
```

A stage doc that lacks any of these is incomplete.

## 4. The macro-arc

The eight stages form three nested arcs:

| Arc | Stages | Felt sense |
|---|---|---|
| **Pre-personal** | Infrared, Magenta | Sub-egoic; before stable separate self. The world is fused, magical, undifferentiated. |
| **Personal** | Red, Amber, Orange, Green | Egoic; stable separate self navigating power, belonging, reason, plurality. |
| **Trans-personal** | Teal, Turquoise | Post-egoic; egoic self transcended-and-included into larger holons. |

The narrative architecture (`narrative/00-narrative-architecture.md`)
treats each arc as a *world-region* — three macro-acts in the
protagonist's journey.

## 5. The vertical seam — sub-octave recapitulation

Each stage internally recapitulates *the entire octave* as
sub-stages. This is the holographic principle from
`foundations/06-law-of-one-correspondence.md`. Practical
consequence: a stage's bestiary should include enemies that *feel*
like miniature versions of every other stage. Examples:

- **Inside Red stage:** there is a "Red-of-Red" warlord
  (most-typical), a "Red-of-Amber" warband (group-bound power),
  a "Red-of-Orange" mercenary (rational power), etc.
- **Inside Orange stage:** there are Orange-flavoured echoes of
  Magenta (orange-rationalised magic = scientism's blind spots),
  Red (orange-rationalised power = Machiavellian), etc.

This sub-octave layer gives each stage *texture* and explains why a
high-altitude player at Orange still meets challenges that *taste*
like Red — the shadow of power-hunger never fully disappears, it
gets sublimated.

In MVP, each stage's bestiary should include **at minimum**:

- 8 side-character archetypes (one per line at this stage's altitude)
- 3–4 sub-octave-flavoured side-character variants (for texture)
- 3 mini-boss archetypes (dual-line)
- 1 main boss (synthesis)
- 1–2 shadow encounters (this stage's typical pathologies)

That's ~16 enemy concepts per stage. Across 8 stages, ~130 enemy
concepts — large but tractable. The detailed stat blocks come later;
the *concepts* are foundational.

## 6. Stage advancement criteria — the universal gate

Every stage gates progression through the same six checks
(detailed per-stage in each world bible):

1. **All 8 lines ≥ this stage's altitude** (the floor)
2. **At least 2 lines ≥ next stage's altitude** (the pull)
3. **All 4 quadrants demonstrated** at this stage's altitude
4. **Main boss synthesis exam cleared**
5. **No active shadow signals at altitude ≤ this stage** (integration check)
6. **At least one *value commitment* held during the stage's main
   arc** (intentionality check — the player has *chosen* something
   that organises their play)

The sixth check is the integrity glue. A player can pass the first
five mechanically while staying internally fragmented; the value
commitment forces a moment of *self-authorship*, which is what
genuine stage transition requires.

## 7. Cross-stage reading order

For a designer / contributor entering the stages layer:

1. Read this overview.
2. Read the **first** stage doc (`stages/01-infrared-archaic.md`) in
   full to internalise the world-bible template.
3. Skim the **last** stage doc (`stages/08-turquoise-superintegral.md`)
   to feel the arc's destination.
4. Then read 02 → 07 in order, looking for the developmental
   *gradients* (how the eight lines transform stage-to-stage; how
   the world's aesthetic evolves; where the shadow material lives).

Reading in this order surfaces the seam: the *shape* of the ascent,
not just the individual stations.

## 8. Open questions

- **Compression of the arc.** Real human stage development takes
  decades. Compressed to a game, what is the *temporal honesty
  ratio*? Each stage should be playable in 10–20 hours of focused
  play in MVP; the dashboard must include a clear disclaimer about
  in-game stage being a *practice indicator*, not a clinical
  attainment.
- **Returning to earlier stages.** Players unlock previous stages
  for shadow work, but the world should not feel "regressive." How
  do we frame return-visits as integration, not punishment? Default:
  visited stages get a "memory dungeon" overlay — the world looks
  familiar but has new content visible only at the player's current
  altitude.
- **Cross-cultural stage descriptions.** Each stage's narrative
  archetypes draw from many traditions. Per-stage docs must vet for
  cultural reductiveness.

## 9. Principles served

Principles **1, 4, 5** — the macro-progression spine, made
playable, made legible to designers.
