# lines/06 — Somatic Line

> **Cross-references:** [[docs/foundations/07-neuroscience-of-development|07 — Neuroscience Of Development]] · [[docs/foundations/03-lines-of-intelligence-overview|03 — Lines Of Intelligence Overview]]

## 1. Purpose

Specify the Somatic line — the capacity to *inhabit and skilfully use the
body*. Mysterium's dodge, posture, breath-gate, and rhythm verbs live here.
Somatic is one of the two lines (with Willpower) that develops
*relatively independently* of cognitive altitude — a skilled dancer or
martial artist may sit at Amber cognitive but Teal somatic.

The somatic line is the line that prevents Mysterium from collapsing into a
*head game*. Every cognitive task is grounded in a body that breathes,
postures, dodges, and times.

## 2. Scientific basis

### 2.1 Construct definition

Synthesis:

- **Hanna (1988, *Somatics*)** — somatic awareness as the proprioceptive
  capacity to feel the body from inside.
- **Aposhyan (2004, *Body-Mind Psychotherapy*)** — somatic intelligence
  as a developmental line.
- **Wilber** — somatic / kinaesthetic line; bodies-gross, subtle,
  causal as state-correlates.
- **Damasio's somatic-marker hypothesis** — bodily signals as
  decision-relevant information.
- **Gardner** — bodily-kinaesthetic as one of the multiple
  intelligences.

Mysterium's working definition:

> Somatic intelligence is the capacity to (a) sense the body
> proprioceptively, (b) coordinate movement under load, (c) regulate
> arousal through breath and posture, and (d) read bodily signals as
> information.

### 2.2 Validated assessments and analogues

| Domain | Assessment / proxy |
|---|---|
| Proprioceptive accuracy | Joint-angle reproduction; body-tilt thresholds |
| Coordination under load | Dual-task posture studies |
| Interoception | Heartbeat-detection task (Schandry) |
| Breath-paced motor control | Resonant-frequency breathing under task |
| Rhythm | Sensorimotor-synchronisation tapping |

### 2.3 Brain regions

Cerebellum, premotor / SMA, primary motor, posterior insula
(interoception), basal ganglia (timing). See `foundations/07`.

## 3. Stage trajectory

| Stage | Capacity | In-game expression |
|---|---|---|
| Infrared | Pure reflex; no felt sense | Auto-dodge windows; no skill expression |
| Magenta | Body-fantasy — "my body is magic"; feeling-tone | Posture buffs; body-as-vessel |
| Red | Power-body — strength, speed, dominance | Power moves; muscular expression |
| Amber | Disciplined-body — coordinated forms; group rhythm | Stance forms; martial arts kata; coordinated rituals |
| Orange | Skilled-body — multi-domain mastery; rational training | Per-skill drills; technique trees |
| Green | Listening-body — attuned to subtle signals; somatic empathy | Body-scan reads; co-presence with others |
| Teal | Integrated-body — body-mind-emotion as one | Compound stances; effort-rest-effort cycling at will |
| Turquoise | Luminous-body — body as energy; non-grasping movement | Effortless moves; presence over technique |

## 4. Game-design mapping

### 4.1 Assessment modality affinity

**Dodger, rhythmist, presence-fighter.** Somatic-leaning builds excel at
real-time windows — perfect parries, tight dodges, breath-gated burst
attacks. They lose to heavy-cognition encounters that require
sustained working memory but win against opponents whose telegraphs the
player has *learned to feel*.

The somatic build is the build a martial-arts-experienced player will
gravitate to.

### 4.2 Assessment tasks / defences / skills

| Verb | Task vehicle | Mechanic | Stage gating |
|---|---|---|---|
| Reflex Dodge | Reaction time | Tap within window matching telegraph | Infrared+ |
| Postured Stance | Sustained posture (held input) | Damage mitigation while held; cost in stamina | Magenta+ |
| Breath-Gate | Breath-paced charge | Bar fills in time with breath cadence; release on exhale | Amber+ |
| Rhythmic Combo | Sensorimotor synchronisation | Inputs in time with a beat; off-beat = no damage | Amber+ |
| Body-Scan Read | Interoception | Tap which of own body-zones is currently tense; correct = buff | Orange+ |
| Subtle-Signal Attune | Anticipatory dodge | Dodge before the visual cue, on the *intention* signal | Green+ |
| Effortless Strike | Compound posture + breath + intention | All three locks held → free heavy attack | Teal+ |
| Presence | Non-action "stance" | Take no action for a beat; full HP / stamina regen; only available at Turquoise | Turquoise |

### 4.3 Module parameters(s) backed

- **Agility** — reflex windows; primary input to real-time encounter pacing
- **Stamina** — posture / breath-gate budget
- **Presence** — late-game; non-action mitigation and regen

### 4.4 Cognitive task vehicles

- Reaction-time tasks (with stimulus-response compatibility variants)
- Rhythm tapping (with off-beat distractors)
- Held-input stability under interference (posture mini-games)
- Breath-paced inputs (calibrated to player's resting rate)
- Interoceptive labelling (body-scan multiple-choice)

### 4.5 Depth progression

Somatic altitude moves quickly at first (Infrared → Amber covers basic
reflex / posture / rhythm), then plateaus until the player engages
breath / interoceptive sub-tasks. The line is the most physically
embodied — players get tired, and the staircase must not pretend
otherwise.

Per-session somatic time should be capped (~10 minutes of intense
somatic-mode play before a forced break or shift to other-line content).
Designed in `docs/progression/00-progression-overview.md`.

## 5. Enemy / encounter structure

### 5.1 Module-level encounters archetypes

| Stage | Side-character | Encoded test |
|---|---|---|
| Infrared | "Pounce-Beast" — fast reflex challenge | Reaction time |
| Magenta | "Body-Glamour" — projects a felt-sense aura | Posture / felt-sense detection |
| Red | "Striker" — power-trades; dodge-or-die | Reaction × intensity |
| Amber | "Form-Master" — punishes broken stance | Sustained posture |
| Orange | "Drill-Sergeant" — multi-skill rapid-fire | Skill switching with motor focus |
| Green | "Mirror-Dancer" — moves the player must mirror | Sensorimotor sync |
| Teal | "Breath-Wraith" — synchronised to player's breath; out-of-sync hurts | Breath-paced inputs |
| Turquoise | "Still One" — only damaged when player takes no action | Presence |

### 5.2 Cross-line encounterses

- **Somatic × Cognitive:** "The Drumheart" — n-back stimuli matched on
  beat. Primary somatic mini-boss.
- **Somatic × Emotional:** "The Felt-Sense Demon" — affect-channel
  while sustaining a posture; slipping breaks both.
- **Somatic × Willpower:** "The Endurance Test" — long-form posture under
  fatigue; willpower stabilises stamina drain.

### 5.3 Main-boss role

Somatic phases of synthesis exams typically appear as the *opening
phase* — establish rhythm, posture, breath. Failure here costs ATB for
the rest of the fight. Late-game synthesis exams add somatic phases at
the climax (Teal / Turquoise) to test integration under exhaustion.

### 5.4 Shadow encounters

**"The Disembodied"** — at Orange stage. The shadow of cognitive
over-development with somatic neglect. The fight gives the player a
body that *will not respond cleanly* — small input-lag, slight desync.
The win condition is to *abandon planning* for one phase and play
purely on rhythm and dodge — body before mind.

**"The Dissociated"** — at Green stage. The shadow of subtle-line
over-development with body avoidance. The fight surfaces a numbed body;
defeated by a body-scan task that requires the player to honestly
report bodily tension before the next attack lands.

## 6. Architectural contract

```
const SOMATIC_VERBS = {
  reflexDodge:     { task: 'reaction_time',          altitudeMin: 'Infrared' },
  posturedStance:  { task: 'held_input_stability',   altitudeMin: 'Magenta'  },
  breathGate:      { task: 'breath_paced_charge',    altitudeMin: 'Amber'    },
  rhythmicCombo:   { task: 'sensorimotor_sync',      altitudeMin: 'Amber'    },
  bodyScanRead:    { task: 'interoceptive_label',    altitudeMin: 'Orange'   },
  subtleAttune:    { task: 'anticipatory_dodge',     altitudeMin: 'Green'    },
  effortlessStrike:{ task: 'compound_lock',          altitudeMin: 'Turquoise'},
  presence:        { task: 'non_action',             altitudeMin: 'White'    },
} as const;

interface SomaticProfile {
  altitude:           Stage;
  fatigueMs:          number;       // accumulates during somatic-mode play
  breathRateBpm:      number | null; // optional, set if device or paced-breath onboarding
  rhythmSyncAccuracy: number;
  interoceptiveAcc:   number;
}
```

The fatigue meter is a *real-world* signal — the system softens
somatic-DDA after sustained heavy somatic play, regardless of in-game
performance.

## 7. Open questions

- **Hardware affordances.** Breath rate, heart rate, and gyroscope are
  available on most modern phones but require permissions and battery
  budget. Mysterium's MVP assumes touch-only; sensor integration is a
  stretch goal.
- **Accessibility.** Somatic mechanics must have alternatives for
  players with motor differences. Default: any timing-critical mechanic
  has a "patience mode" with widened windows; this *does not*
  artificially inflate altitude — the staircase tracks it.
- **Cultural movement vocabulary.** Breath-paced inputs and rhythm
  combos draw from many traditions (qigong, pranayama, capoeira,
  tabla). Honour the lineages without reducing them to flavour.

## 8. Principles served

Principles **1, 4, 5** — body as a first-class line, earned via real
embodied practice, with UX humility about player physicality.
