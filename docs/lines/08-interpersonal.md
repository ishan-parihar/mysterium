# lines/08 — Interpersonal Line

> **Cross-references:** [[docs/foundations/01-aqal-quadrants|01 — Aqal Quadrants]] · [[docs/foundations/03-lines-of-intelligence-overview|03 — Lines Of Intelligence Overview]]

## 1. Purpose

Specify the Interpersonal line — the capacity to *attune to and engage
other selves*. Mysterium's co-op synergies, party-buffs, attunement reads,
and conflict-resolution mechanics live here. Interpersonal is the line
that lives in the **LL quadrant** (collective interior) — where
"we-space" is generated.

A single-player game can *practice* interpersonal capacity (NPC
dialogues, ally party management) but only multiplayer can *test* it
honestly. Mysterium's hardest interpersonal milestones are multiplayer-only
by design — a deliberate constraint, defended in `lines/00`.

## 2. Scientific basis

### 2.1 Construct definition

Synthesis:

- **Gardner** — interpersonal as one of the multiple intelligences.
- **Salovey-Mayer** — social-emotional intelligence as a meta-domain.
- **Wilber / Kegan** — *we-space*; capacity to hold others as full
  subjects, not as objects of one's own narrative.
- **Empathy literature (Davis IRI; de Waal; Singer)** — cognitive
  vs. affective vs. compassionate empathy; perspective-taking.
- **Theory of mind (Frith & Frith)** — the mental architecture of
  representing others' minds.

Mysterium's working definition:

> Interpersonal intelligence is the capacity to (a) accurately model
> another mind, (b) attune to another's affect, (c) coordinate action
> with another agent, and (d) repair rupture when coordination fails.

### 2.2 Validated assessments

| Assessment | Measures |
|---|---|
| IRI (Interpersonal Reactivity Index) | Cognitive empathy, affective empathy, fantasy, personal distress |
| Reading the Mind in the Eyes (Baron-Cohen) | Mental-state inference from minimal cues |
| False-belief tasks | Theory of mind |
| Coordination latency in dyadic tasks | Sensorimotor / social attunement |
| Repair / rupture tasks (clinical) | Conflict-resolution capacity |

### 2.3 Brain regions

Temporoparietal junction, medial PFC, precuneus, posterior cingulate,
mirror system. The "social brain" intersects default-mode and frontal
regions for self-other modelling.

## 3. Stage trajectory

| Stage | Capacity | In-game expression |
|---|---|---|
| Infrared | Pre-social; co-presence only | NPCs as backdrop |
| Magenta | Magical-others — fused / fantasy projections | Imagined others; fantasy companions |
| Red | Egocentric-others — others as instruments | Allies as tools; betrayal logic |
| Amber | Conformist-others — in-group bonding, out-group opaque | Tribal allies; party bound by shared rule |
| Orange | Rational-others — contractual coordination | Specialised parties; clear roles |
| Green | Pluralistic-others — many valid relational styles | Diverse parties; relational nuance |
| Teal | Integral-others — multiple selves attuned at multiple levels | Holonic teams; cross-stage attunement |
| Turquoise | Non-dual others — no fixed boundary self/other | Communion; merged action |

## 4. Game-design mapping

### 4.1 Assessment modality affinity

**Coordinator, attuner, healer, conflict-resolver.** Interpersonal
builds shine in co-op — they cannot solo high-altitude content
efficiently because the line *requires another mind to be exercised*.
The interpersonal player is the one whose *party* punches above its
weight, even if they themselves do mediocre damage.

In single-player, interpersonal is exercised through NPC ally
management — but the altitude ceiling is **lower in single-player than
multiplayer**, by design.

### 4.2 Assessment tasks / defences / skills

| Verb | Task vehicle | Mechanic | Stage gating |
|---|---|---|---|
| Attune | Read partner's intent | Dyadic affect / intent recognition; correct → coordinated next-move buff | Red+ |
| Signal | Communicate intent without language | Limited symbolic gestures with cooldowns; partner reads | Amber+ |
| Support | Boost ally action | Ally action × 1.15 if support tap is in time with their input | Amber+ |
| Co-Parry | Joint defensive | Both players parry on shared timing; failure costs both | Orange+ |
| Rally | Restore party morale after a loss | Brief rhythm task; success resets fatigue across party | Orange+ |
| Hold the We-Space | Sustain group coherence under pressure | Multi-channel task: own affect + partner affect + shared goal | Green+ |
| Cross-Style Synthesis | Compose two parties' build philosophies | Buff if both philosophies hit synergy threshold | Teal+ |
| Communion | Merge action briefly | Synced inputs from both players → single super-action | Turquoise (multiplayer-only) |

### 4.3 Module parameters(s) backed

- **Attunement** — read accuracy on partner state
- **Coordination** — input-sync latency tolerance with partner
- **Repair** — speed of party-morale recovery after rupture

### 4.4 Cognitive task vehicles

- Coordinated rhythm tasks (dyadic tapping)
- Theory-of-mind / false-belief embedded in dialogue
- Affect-recognition tasks (faces, vocal tone) where the target is the
  ally
- Conflict-resolution mini-games (partner expresses upset; player
  selects from response options; partner rates)

### 4.5 Depth progression

Single-player interpersonal advancement caps at **Orange** in MVP.
Multiplayer is required to advance to Green and beyond. This is a hard
rule — defended in `foundations/01-aqal-quadrants.md` (LL is the
collective-interior; collective intelligence requires actual collective
engagement).

In multiplayer, interpersonal altitude moves with consistent partnered
play, not from solo grind.

## 5. Enemy / encounter structure

### 5.1 Module-level encounters archetypes

| Stage | Side-character | Encoded test |
|---|---|---|
| Infrared | "Stranger" — non-interactive | None; presence only |
| Magenta | "Phantom-Ally" — imagined helpful presence | Fantasy partner; player must engage as if real |
| Red | "Power-Ally" — useful while convenient | Transactional partnership |
| Amber | "Tribe-Member" — strict in-group code | Tribal-rule conformity |
| Orange | "Contractor-Partner" — clear expectations | Role coordination |
| Green | "Plural-Ally" — different style requiring adaptation | Style attunement |
| Teal | "Cross-Stage Mentor" — partner at different altitude | Asymmetric attunement |
| Turquoise | "Communion" — fellow-being indistinguishable from self | Merged action |

### 5.2 Cross-line encounterses

- **Interpersonal × Cognitive:** "The Strategist Pair" — two enemies
  whose attacks are coordinated; player must mirror with own ally.
- **Interpersonal × Emotional:** "The Crowd" — ten NPCs with affect
  states; managing one destabilises others.
- **Interpersonal × Moral:** "The Coalition" — three NPCs needing
  conflicting allocations; reading mind + reading affect required.

### 5.3 Main-boss role

A stage's main boss has an **interpersonal phase** typically structured
as:

- Single-player: an NPC ally appears and must be coordinated with
  through a coordination puzzle.
- Multiplayer: a phase that *requires* both/all players to coordinate
  against a divide-and-conquer boss; failure to attune costs both.

Late-stage bosses (Teal, Turquoise) cannot be defeated solo at the
highest tier; they require multiplayer.

### 5.4 Shadow encounters

**"The Lone Wolf"** — at Orange stage. The shadow of cognitive /
willpower over-development with interpersonal repression. The boss
mirrors the player exactly except they cannot be defeated alone. The
win condition is to *call in an ally* (NPC in single-player; another
player in multiplayer) and demonstrate one full coordination action.
Lesson: integration includes belonging.

**"The Merger"** — at Green stage. The shadow of interpersonal
over-development with self-loss. The boss is a beguiling ally
proposition; accepting causes the player's own line altitudes to
*decrease*. Defeated by a moment of *boundary-setting* — saying no to
the offer of merger.

## 6. Architectural contract

```
const INTERPERSONAL_VERBS = {
  attune:               { task: 'partner_intent_read', altitudeMin: 'Red' },
  signal:               { task: 'symbolic_gesture',    altitudeMin: 'Amber' },
  support:              { task: 'timed_buff',          altitudeMin: 'Amber' },
  coParry:              { task: 'sync_defence',        altitudeMin: 'Orange' },
  rally:                { task: 'morale_rhythm',       altitudeMin: 'Orange' },
  holdWeSpace:          { task: 'multichannel_hold',   altitudeMin: 'Green' },
  crossStyleSynthesis:  { task: 'build_synergy',       altitudeMin: 'Turquoise' },
  communion:            { task: 'merged_action',       altitudeMin: 'White', multiplayerOnly: true },
} as const;

interface InterpersonalProfile {
  altitude:                Stage;
  altitudeCeilingSolo:     Stage;     // Orange in MVP
  partneredSessionsPlayed: number;
  attunementAccuracy:      number;
  coordinationLatencyMs:   number;
}
```

Multiplayer-only verbs guarded at the use-case layer: attempting to
trigger Communion in single-player returns a tagged error that the UI
surfaces gracefully.

## 7. Open questions

- **Asynchronous multiplayer.** Live multiplayer is hard for many
  players (latency, schedule). An asynchronous mode (turn-based with
  party of friends) preserves *some* interpersonal training; whether it
  preserves enough to gate altitude advancement is an open question.
  Default: live ≥ Green; async only counts up to Orange.
- **Cross-cultural attunement.** Affect cues vary by culture; partner
  pools may be cross-cultural. Honest UX: show the partner's stated
  cultural-affect-style preference as part of party setup.
- **Toxicity.** Interpersonal play in multiplayer is *exactly* where
  toxicity lives. Mysterium must build robust pro-social structures
  (party-of-friends emphasis; voice-off default; report flows). See
  `validation/02`.

## 8. Principles served

Principles **1, 4, 5, 6** — closes the AQAL quadrant coverage with the
LL line, gates progression to multiplayer where appropriate, accepts
the UX cost of doing so honestly, and protects players from each other.
